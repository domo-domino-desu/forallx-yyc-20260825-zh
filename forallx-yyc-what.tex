\chapter{论证}
\label{s:Arguments}

正如在\hyperref[preface]{前言}中提到的，逻辑有\emph{很多}用途。我们在这里将重点关注它在评估论证方面的应用：区分好的论证与坏的论证。

在日常语言中，我们有时用“论证”这个词来指充满火药味的争吵\footnote{译注：英文中，论证和争吵是同一个词（argument）。}。如果你和一位朋友在这种意义上发生了争论，那说明你们俩的关系可不太妙。逻辑不关心这种咬牙切齿和互相揪扯的争吵。它们不是我们意义上的论证；它们仅仅是意见分歧。

我们将要理解的论证，更像是这样的东西：


\begin{earg}\label{argButlerGardner}
		\item 要么是管家干的，要么是园丁干的。
		\item 不是管家干的。
		\item[\texttherefore] 是园丁干的。
	\end{earg}


这里我们有一个句子序列。论证第三行的三个点读作“所以”。它们表明最后一个句子表达的是论证的\emph{结论}。它之前的两个句子是论证的\emph{前提}。如果你相信这些前提，并且认为结论是从这些前提得出的——也就是说，这个论证是有效的——那么这（或许）为你相信这个结论提供了一个理由。

这就是逻辑学家感兴趣的那种东西。我们会说，论证就是由一组前提及一个结论构成的。

本部分讨论一些适用于像英语这样的自然语言论证的基本逻辑概念。一开始就清楚地理解什么是论证以及什么是论证的有效性，这很重要。之后，我们将用一种形式语言来表示自然语言论证。 %We want formal validity, as defined in the formal language, to have at least some of the important features of natural-language validity.

在刚刚给出的例子中，我们用单独的句子表达了论证的两个前提，并用第三个句子表达了论证的结论。许多论证都是以这种方式表达的，但一个单一的句子本身就可以包含一个完整的论证。考虑：


\begin{quote}
		 管家有不在场证明；所以这件事不可能是管家干的。
	\end{quote}


这个论证有一个前提，后面跟着一个结论。

许多论证以前提开始，以结论结束，但并非全部如此。本节开头的那个论证，同样可以把结论放在开头来呈现，像这样：


\begin{quote}
		是园丁干的。毕竟，要么是管家干的要么是园丁干的。而管家没干。
	\end{quote}


同样，它也可能把结论放在中间呈现：


\begin{quote}
		不是管家干的。所以是园丁干的。毕竟，要么是园丁干的要么是管家干的。
	\end{quote}


面对一个论证时，我们想知道结论是否从前提得出。所以首先要做的是将结论与前提分开。作为指引，这些词通常用来指示论证的结论：


\begin{center}
		所以，因此，因而，于是，相应地，从而
	\end{center}


因此，它们有时被称为\define{结论提示词（conclusion
indicator words）}。

相比之下，以下表达式是\define{前提提示词（premise indicator words）}，因为它们通常指示我们正在处理的是前提而非结论：


\begin{center}
		既然，因为，鉴于
	\end{center}


但在分析论证时，没有什么能替代敏锐的洞察力。

}

\section{句子}
\label{intro.sentences}

为了完全一般化，我们可以将一个\define{论证（argument）}定义为一个句子序列。序列开头的句子是前提。序列的最后一个句子是结论。如果前提为真且论证是好的，那么你就有理由接受这个结论。

在逻辑学中，我们只对那些能够作为论证的前提或结论的句子感兴趣，即那些可以为真或为假的句子。因此，我们将自己限定在这类句子上，并将\define{句子（sentence）}定义为可以为真或为假的句子。

你不应当混淆“句子可以为真或为假”这一观念与“事实与观点”之间的区别。通常，逻辑中的句子可以表达那些算作事实的事情——例如“Rudolf Carnap 出生在 Ronsdorf”或“Simone de Beauvoir 喜欢散步”。它们也可以表达那些你可能认为是观点的事情——例如，“大黄很好吃”。换言之，不能因为我们不知道某个句子的真假，或者其真假属于观点问题，就剥夺它作为论证一部分的资格。只要它是那种可以为真或为假的句子，它就可以扮演前提或结论的角色。

此外，有一些在语言学或语法课中算作“句子”的东西，在我们这里不会被算作逻辑中的句子。

\paragraph{疑问句} 在语法课上，“你困了吗？”会被算作一个疑问句。虽然你可能困了或者你可能很清醒，但这个问题本身既不真也不假。因此，疑问句在逻辑中不被算作句子。假设你回答这个问题：“我不困。”这个回答要么真要么假，因此它在逻辑意义下是一个句子。一般而言，\emph{疑问句}不算句子，但\emph{回答}算。

“这门课是关于什么的？”不是一个句子（在我们的意义上）。“没人知道这门课是关于什么的”是一个句子。

\paragraph{祈使句} 命令常以祈使句形式表达，如“醒来！”、“坐直”等等。在语法课上，这些会被算作祈使句。尽管坐直对你来说可能有益也可能无益，但命令本身既不为真也不为假。然而要注意，命令并不总是以祈使句形式表达。“你会尊重我的权威”\emph{是}要么真要么假的——你要么会要么不会——因此它在逻辑意义下算作一个句子。

\paragraph{感叹句} “哎哟！”有时被称为感叹句，但它既不真也不假。我们会把“哎哟，我伤到脚趾了！”看作和“我伤到脚趾了”意思相同。“哎哟”并没有增加任何可以为真或为假的内容。

\chapter{逻辑的范围}
\label{s:Valid}

\section{后承与有效性}

在\cref{s:Arguments}中，我们讨论了论证，即由一组句子（前提）后跟一个单独的句子（结论）构成的东西。我们说过，像“因此”这样的一些词指示哪个句子应该是结论。“因此”当然暗示了前提和结论之间存在一种联系，即结论\emph{从前提得出}，或者说\emph{是前提的后承}。

后承这一概念是逻辑学关注的核心内容之一。人们甚至可以说，逻辑学就是一门研究“能从什么得出什么”的科学。逻辑学发展出了相关的理论和工具，用以告诉我们一个句子何时能从另一些句子得出。

那么，在\cref{s:Arguments}中讨论的那个主要论证呢？


\begin{earg}
	\item[] 要么是管家干的，要么是园丁干的。
	\item[] 不是管家干的。
	\item[\texttherefore] 是园丁干的。
\end{earg}

我们没有任何语境来判断这个论证中的句子指称什么。也许你怀疑这里的“干”意味着是某个未具体说明的罪行的“作案者”。你可以想象这个论证出现在一部推理小说或电视节目中，也许是由一位正在梳理证据的侦探说出的。但即使没有任何这类信息，你也很可能同意这个论证是“好的”，其意义在于：无论前提指的是什么，如果它们都为真，结论就不可能不为真。如果第一个前提为真，即“要么是管家干的，要么是园丁干的”为真，那么不管“干”是什么意思，至少他们中有一人“干”了这回事。而如果第二个前提为真，那么管家没有“干”。这就只剩下一个选项：“是园丁干的”必定为真。在这里，结论从前提得出。我们称具有这种性质的论证为\define{有效的（valid）}。

作为对比，考虑以下论证：

\begin{earg}\label{argMaidDriver}
	\item[] 如果是司机干的，那么就不是女佣干的。
	\item[] 不是女佣干的。
	\item[\texttherefore] 是司机干的。
\end{earg}

我们仍然不知道这里在谈论什么。但是，你很可能同意这个论证与上一个论证在一个重要方面有所不同。如果前提为真，并\emph{不}能保证结论也为真。这个论证的前提本身并没有排除女佣或司机之外的人“干了”的可能性。因此，存在一种情况：两个前提都为真，然而不是司机干的，即结论不真。在这第二个论证中，并不能从前提中得出结论。如果像这个论证一样，结论不从前提得出，我们就说它是\define{无效的（invalid）}。

\section{情况与有效性的类型}

我们是如何确定第二个论证是无效的呢？我们指出了一种前提为真而结论不为真的情况。这就是司机和女佣都没干，而是某个第三人干了的场景。我们把这样的情况称为该论证的一个\define{反例（counterexample）}。如果一个论证存在反例，结论就不可能是前提的后承。要想让结论成为前提的后承，前提的真必须保证结论的真。如果存在反例，前提的真就不能保证结论的真。

作为逻辑学家，我们希望能够确定何时一个论证的结论从前提得出。并且，如果没有反例——即不存在所有前提都为真而结论不真的情况——结论就是前提的后承。这启发了如下的定义：

	\factoidbox{
		一个语句 $A$ 是语句 $B_1$, \dots, $B_n$ 的\define{后承（consequence）}，当且仅当不存在 $B_1$, \dots, $B_n$ 都真而 $A$ 不真的情况。（此时我们也说 $A$ 从 $B_1$, \dots, $B_n$\define{得出（follows from）}，或者说 $B_1$, \dots, $B_n$\define{蕴涵（entail）}~$A$。）
	}

这个“定义”是不完整的：它没有告诉我们“情况”是什么，或者“在一种情况下为真”意味着什么。到目前为止，我们只看到了一个例子：一个涉及三个人的假设场景。在这个场景中的三个人——司机、女佣和某个第三人——司机和女佣没干，但第三人干了。在这个所描述的场景中，司机没干，因此这是一种“司机干了”这一语句不为真的情况。我们第二个论证的前提为真，但结论不真：这个场景就是一个反例。

我们说过，结论是前提后承的论证被称为有效的，结论不是前提后承的论证被称为无效的。既然我们现在至少对“后承”有了初步的尝试性定义，我们就把它记录下来：

	\factoidbox{


\begin{factoiditems}
			\item 一个论证是\define{有效的（valid）}当且仅当其结论是前提的后承。
			\item 一个论证是\define{无效的（invalid）}当且仅当它不是有效的，即它有一个反例。
		\end{factoiditems}

}

\newglossaryentry{valid}
{
name=有效的,
description={论证的一种属性，其结论是前提的后承}
}

\newglossaryentry{invalid}
{
name=无效的,
description={当结论不是前提的后承时论证所具有的属性；与 \gls{valid} 相反}
}

逻辑学家的工作就是让“情况”这个概念变得更精确，并研究当“情况”以这种或那种方式被精确化时，哪些论证是有效的。如果我们把“情况”理解为像第二个论证的反例那样的“假设场景”，那么很明显，第一个论证算作是有效的。如果我们想象一个场景：要么管家要么园丁做了，并且管家没做，那么我们就自动地想象了一个园丁做了的场景。因此，任何使第一个论证的前提为真的假设场景，都会自动使其结论为真。这使得第一个论证成为有效的。

通过将“情况”解释为“假设场景”来使其更具体，是一种进步。但这并非事情的终点。第一个问题是我们不知道什么才算作一个假设场景。它们受物理定律的限制吗？受非常宽泛意义上可构想之物的限制吗？我们对这些问题的回答，决定了我们将哪些论证算作有效的。

假设对第一个问题的回答是“是的”。考虑以下论证：


\begin{earg}
		\item[] 飞船“Rocinante号”从Tycho空间站到木星花了六个小时。
		\item[\texttherefore] Tycho空间站与木星之间的距离小于 140 亿公里。
	\end{earg}


这个论证的一个反例将是这样一个场景：“Rocinante号”在 6 小时内完成了超过 140 亿公里的旅程，超过了光速。由于这样的场景与物理定律不相容，如果假设场景必须符合物理定律，就不存在这样的场景。然而，如果假设场景不受物理定律的限制，就存在一个反例：“Rocinante号”超光速飞行的场景。

假设对第二个问题的回答是“是的”，并考虑另一个论证：


\begin{earg}
		\item[] Priya 是一名眼科医生（ophthalmologist）。
		\item[\texttherefore] Priya 是治疗眼睛的人（eye doctor）。
	\end{earg}


如果我们只允许构想得出的场景，这个论证也是有效的。如果你想象 Priya 是一名眼科医生，你就因此想象了 Priya 是治疗眼睛的人。这正是“ophthalmologist”和“eye doctor”的含义。不存在 Priya 是眼科医生但不是治疗眼睛的人的场景，这被这两个词之间的概念联系排除了。

根据我们将哪些类型的情况视为潜在的反例，我们会得出不同的后承与有效性概念。有效性的特征是不存在反例。但对不同的概念而言，什么算作反例可能有所不同。例如，我们可能会排除违反自然定律的反例，或者排除违反像“eye doctor”和“ophtalmologist”这样的词之间概念联系的反例。因此，如果一个论证不存在遵守自然定律的反例，我们可以称其为\define{法则上有效的（nomologically valid）}；如果一个论证不存在遵守词汇间概念联系的反例，我们可以称其为\define{概念上有效的（conceptually valid）}。对于这两种有效性概念而言，世界的某些方面（例如，自然定律是什么）和论证中句子意义的某些方面（例如，“ophthalmologist”意思就是一种 eye doctor）都会影响一个论证是否算作有效的。

\section{形式有效性}\label{s:FormalValidity}

然而，\emph{逻辑}后承的一个显著特征是，它不应当依赖于前提和结论的内容，而只依赖于它们的逻辑形式。换句话说，作为逻辑学家，我们想要发展一种理论，来捕捉论证能够成为有效的另一种方式。例如，

\begin{earg}
	\item[] Priya 要么是一名眼科医生，要么是一名牙医。
	\item[] Priya 不是牙医。
	\item[\texttherefore] Priya 是治疗眼睛的人。
\end{earg}

和

\begin{earg}
	\item[] Priya 要么是一名眼科医生，要么是一名牙医。
	\item[] Priya 不是牙医。
	\item[\texttherefore] Priya 是一名眼科医生。
\end{earg}

都是有效的论证。但第一个论证的有效性依赖于内容（即“ophthalmologist”和“eye doctor”的意义），而第二个则不依赖。第二个论证是\define{形式有效的（formally valid）}。我们可以将这个论证的“形式”描述为一种模式，大致如下：

\begin{earg}
	\item[] $A$ 要么是一个 $X$，要么是一个 $Y$。
	\item[] $A$ 不是一个 $Y$。
	\item[\texttherefore] $A$ 是一个 $X$。
\end{earg}

这里的 $A$、$X$ 和 $Y$ 是占位符，代表适当的表达式；将适当的表达式代入 $A$、$X$ 和 $Y$，就能将该模式变为由句子构成的论证。例如，

\begin{earg}
	\item[] 梅要么是一位数学家，要么是一位植物学家。
	\item[] 梅不是一位植物学家。
	\item[\texttherefore] 梅是一位数学家。
\end{earg}

就是一个具有相同形式的论证，但本节开头的第一个论证却不是这种形式：为了从模式中得到它，我们需要将 $Y$ 替换成不同的表达式（一次替换为“治疗眼睛的人”，一次替换为“眼科医生”）。

而且，第一个论证并不是形式有效的。\emph{它的}形式是这样的：

\begin{earg}
	\item[] $A$ 要么是一个 $X$，要么是一个 $Y$。
	\item[] $A$ 不是一个 $Y$。
	\item[\texttherefore] $A$ 是一个 $Z$。
\end{earg}

在这个模式中，我们可以用“治疗眼睛的人”替换 $X$，用“眼科医生”替换 $Z$，从而得到原来的论证。但下面这个论证也具有相同的形式：

\begin{earg}
	\item[] 梅要么是一位数学家，要么是一位植物学家。
	\item[] 梅不是一位植物学家。
	\item[\texttherefore] 梅是一位杂技演员。
\end{earg}

这个论证显然不是有效的，因为我们完全可以想象一位名叫梅的数学家并不是杂技演员。

作为逻辑学家，我们的策略将是提出一种“情形”概念，使得一个论证在这种“情形”下被判为有效，当且仅当它是形式有效的。显然，这种“情形”概念不仅会违反某些自然法则，还会违反某些语言法则。由于第一个论证在这种意义下是无效的，我们必须允许一种构成反例的情形：普里娅是一位治疗眼睛的人，但不是一位眼科医生。这种情形并非是可以设想的：它被“治疗眼睛的人”和“眼科医生”这两个词的含义排除了。

当我们为了评估论证的有效性而考虑各种情形时，我们会做一个重要假设。我们假设，对于所考虑的每个句子，每个情形都使它为真或不真。首先这意味着，任何使论证中某个句子的真假无法确定的假想情景，都不被视为潜在的反例。例如，一个普里娅是牙医但不是治疗眼睛的人的场景，在考虑本节前几个论证时会被当作一种可考虑的情形，但在考虑最后两个论证时则不会：它没有告诉我们梅是否是数学家、植物学家或杂技演员。如果一个情形没有使一个句子为真，我们就说它使这个句子为\define{假（false）}。因此，我们假设情形使句子为真或为假，但不会同时既为真又为假。\footnote{句子要么为真要么为假且不能同时为真的假设，称为“二值性”。即使这个假设在你看来是常识性的，但在逻辑哲学家中它也是有争议的。首先，有些逻辑学家希望考虑句子既不为真也不为假，而是具有某种中间真值的情形。更具争议的是，一些哲学家认为我们应该允许句子同时既为真又为假的可能性。存在一些逻辑系统允许句子既不为真也不为假，或者同时既为真又为假，但本书不会讨论它们。}

\section{可靠的论证}

在我们继续执行这一策略之前，需要做一些澄清。我们已经将论证定义为句子的集合，其中一句（结论）应当从其他句子（前提）得出。这种意义上的论证在日常和科学论述中被广泛使用。当这样使用时，论证被用来支持甚至证明其结论。如果一个论证是有效的，那么它将支持其结论，但\emph{仅当}其所有前提都为真。有效性排除了前提为真而结论同时不为真的可能性。它本身并不排除结论不为真的可能性。换句话说，一个有效论证完全可能拥有一个不真的结论！

考虑这个例子：

\begin{earg}
		\item[] 橘子要么是水果，要么是乐器。
		\item[] 橘子不是水果。
		\item[\texttherefore] 橘子是乐器。
	\end{earg}

这个论证的结论是荒谬的。然而，它确实是从前提推出的。\emph{如果}两个前提都为真，\emph{那么}结论就必然为真。所以这个论证是有效的。

反之，前提为真且结论为真，并不足以使一个论证有效。考虑这个例子：

\begin{earg}
		\item[] 伦敦在英格兰。
		\item[] 北京在中国。
		\item[\texttherefore] 巴黎在法国。
	\end{earg}

这个论证的前提和结论事实上都为真，但该论证是无效的。如果巴黎宣布从法国其他地区独立出去，那么结论将不再成立，尽管两个前提依然为真。因此，存在一种情形，使得该论证的前提为真而结论不为真。所以，这个论证是无效的。

需要记住的重要一点是：有效性并不关乎论证中句子的\emph{实际}真假。它关乎的是，是否\emph{可能}出现所有前提为真而结论同时不为真的情况（在某个假想情形中）。\emph{事实上}是怎样的，在这里并不起特殊作用；事实本身并不能决定一个论证是否有效。\footnote{不过，有一种情况例外：如果前提事实上为真而结论事实上不为真，那么我们就身处一个反例之中；因此该论证是无效的。}关于事物实际状况的任何信息，其本身都不能决定一个论证是否有效。人们常说逻辑不在乎情感。实际上，它也不在乎事实。

那么，当我们用一个论证来证明其结论\emph{为真}时，我们需要两样东西。首先，我们需要论证是有效的；也就是说，结论必须能从前提推出。但我们也需要前提本身为真。我们将说，一个论证是\define{可靠（sound）}的，当且仅当它既是有效的，并且它的所有前提都为真。

\newglossaryentry{sound}
{
name={可靠},
description={论证的一个属性，成立的条件是该论证有效且所有前提为真}
}

反过来，当你想反驳一个论证时，你有两种选择：你可以指出（一个或多个）前提不真，或者你可以指出论证无效。然而，逻辑学只能帮助你处理后一种情况！

\section{归纳论证}

许多好的论证是无效的。考虑下面这个：

\begin{earg}
		\item[] 迄今为止的每一个冬天，卡尔加里都下过雪。
	\item[\texttherefore] 即将到来的这个冬天，卡尔加里也会下雪。
\end{earg}

这个论证从对许多（过去）情形的观察推广到关于所有（未来）情形的结论。这类论证被称为\define{归纳（inductive）}论证。然而，这个论证是无效的。即使卡尔加里迄今为止每年冬天都下雪，那里在整个即将到来的冬天保持无雪仍然是\emph{可能}的。事实上，即使卡尔加里从此以后每年冬天都下雪，我们仍然可以\emph{想象}这样一种情形：今年是第一个整个冬天都不下雪的年份。而这个假想情形，正是该论证的前提为真而结论不为真的一个情形，从而使得该论证无效。

这一切的关键在于，归纳论证——即便是好的归纳论证——也不是（演绎）有效的。它们不是\emph{滴水不漏的}。尽管可能性不大，但即使它们的所有前提都为真，它们的结论也\emph{可能}是假的。在本书中，我们将（完全）搁置“什么构成一个好的归纳论证”这一问题。我们的兴趣仅仅在于区分（演绎）有效的论证与无效的论证。

所以：我们关心的是某些前提是否\emph{蕴含}某个结论。但是，不要说前提\emph{推理（infer）}出结论。蕴涵是前提和结论之间的一种关系；推理则是人做的事情。所以，当结论能从前提推出时，如果你想用推理这个词，你可以说\emph{人们}可以从前提\emph{推理}出该结论。

\section{共同可能性}

考虑下面两个句子：


\begin{compactlist}
		\item[B1.] Jane 唯一的兄弟比她矮。
		\item[B2.] Jane 唯一的兄弟比她高。
	\end{compactlist}


单凭逻辑无法告诉我们这两个句子中哪个为真（如果有的话）。然而我们可以说，\emph{如果}第一个句子（B1）为真，\emph{那么}第二个句子（B2）必定为假。类似地，如果 B2 为真，那么 B1 必定为假。不存在一种可能的情形能让这两个句子同时为真。这两个句子彼此不相容，它们不可能同时为真。这引出了以下定义：
	\factoidbox{
		句子是\define{共同可能的（jointly possible）}，当且仅当存在一个情形使得它们全部为真。
	}
B1 和 B2 是\emph{共同不可能的}；而下面两个句子，例如，就是共同可能的：


\begin{compactlist}
		\item[B1.] Jane 唯一的兄弟比她矮。
		\item[B2.] Jane 唯一的兄弟比她年轻。
	\end{compactlist}

\newglossaryentry{possibility}
{
name=共同可能性,
text={共同可能的},
description={一些句子在单个情形下全部为真时所具有的性质}
}

我们可以询问任意数量句子的共同可能性。例如，考虑以下四个句子：


\begin{compactlist}
		\item[G1.] \label{MartianGiraffes} 野生动物园里至少有四只长颈鹿。
		\item[G2.] 野生动物园里恰好有七只大猩猩。
		\item[G3.] 野生动物园里的火星人不超过两个。
		\item[G4.] 野生动物园里的每一只长颈鹿都是火星人。
	\end{compactlist}


G1 和 G4 共同蕴涵了公园里至少有四只火星长颈鹿。这与 G3 冲突，因为 G3 意味着那里最多只有两只火星长颈鹿。所以句子 G1--G4 是共同不可能的。它们不可能全部为真。（注意，句子 G1、G3 和 G4 已经是共同不可能的了。如果一些句子已经是共同不可能的，那么再往里面添加额外的句子也无法使它们变成共同可能的！）

有件事值得指出来：你可能认为，一个论证只有在其前提是共同可能的时候才“有意义”。然而，我们对“什么是论证”以及“它何时有效”的定义，都不要求这一点。实际上，根据我们的定义，任何前提共同不可能的论证，都是自动有效的！（练习：说服自己这是真的。）

\ifHTMLtarget
\section{必然真理、必然谬误与偶然性}
\else
\section[必然真理与必然谬误]{必然真理、必然谬误与偶然性}
\fi

评估论证的有效性时，我们关心的是：\emph{如果}前提为真，那么什么为真。但有些句子就是\emph{必定}为真的。考虑这几个句子：


\begin{enumerate}
		\item\label{Acontingent} 天正在下雨。
		\item\label{Atautology} 天要么在这里下雨，要么不在。
		\item\label{Acontradiction} 天既在这里下雨，又不在下雨。
	\end{enumerate}


要知道\cref*{Acontingent}是否为真，你需要看看窗外或者查一下天气预报。它可能为真，也可能为假。一个既可以真又可以假（当然，是在不同的情形下）的句子，被称为\define{偶然的（contingent）}。

\newglossaryentry{contingent sentence}
{
name={偶然句子},
description={一个句子既不是\gls{necessary truth}也不是\gls{necessary falsehood}；一个在有些情形下为真，在另一些情形下为假的句子}
}

\Cref*{Atautology}则不同。你不需要看窗外就知道它为真。无论天气怎样，天要么在这里下雨，要么不在。这就是一个\define{必然真理（necessary truth）}。

\newglossaryentry{necessary truth}
{
name={必然真理},
description={一个在所有情形下都为真的句子}
}

同样，你也不需要查看天气来确定\cref*{Acontradiction}是否是真的。仅凭逻辑，它就必定为假。天可能正在这里下雨，而在镇子那边没下；可能现在正在下雨，但当你读完这句话时雨就停了；但天不可能在同一个地方、同一个时间既在下雨又没有下雨。所以，无论世界是怎样的，天都不会既在这里下雨又不在这里下雨。它是一个\define{必然谬误（necessary falsehood）}。

\newglossaryentry{necessary falsehood}
{
name={必然谬误},
description={一个在所有情形下都为假的句子}
}

某个句子可能\emph{总是}为真，却仍然是偶然的。例如，如果宇宙从来不曾包含少于七个事物，那么“至少存在七个事物”这个句子就会一直为真。然而这个句子是偶然的：世界本可能比现在小得多得多，那样的话这个句子就会为假。

\section{必然等值}

我们也可以考察两个句子\emph{之间}的逻辑关系。例如：


\begin{compactlist}
\item[] John 洗完盘子后去了商店。
\item[] John 去商店之前洗了盘子。
\end{compactlist}


这两个句子都是偶然的，因为 John 可能根本没去商店或洗盘子。然而，它们的真值必须相同。如果这两个句子中有一个为真，则两者都为真；如果有一个为假，则两者都为假。当两个句子在每一种情形下都具有相同的真值时，我们说它们是\define{必然等值（necessarily equivalent）}的。

\newglossaryentry{necessary equivalence}
{
name={必然等值},
text={必然等值的},
description={一对句子具有的性质：在所有情形下，它们要么同为真，要么同为假}
}

\section*{逻辑概念总结}

\factoidbox{


\begin{factoiditems}
\item 一个论证是\define{有效的（valid）}，如果不存在前提全真而结论不为真的情形；否则它就是\define{无效的（invalid）}。

\item 一个\define{必然真理（necessary truth）}是在所有情形下都为真的句子。

\item 一个\define{必然谬误（necessary falsehood）}是在所有情形下都为假的句子。

\item 一个\define{偶然的句子（contingent sentence）}既不是必然真理也不是必然谬误；它是一个在有些情形下为真，在另一些情形下为假的句子。

\item 两个句子是\define{必然等值（necessarily equivalent）}的，如果它们在所有情形下都同为真或同为假。

\item 一组句子是\define{共同可能的（jointly possible）}，如果存在一个情形使它们同时为真；否则就是\define{共同不可能的（jointly impossible）}。
\end{factoiditems}


}
